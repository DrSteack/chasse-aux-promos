# 🛒 Chasse aux promos

Appli mobile (PWA) : promos alimentaires près de chez moi (Intermarché, Lidl, Auchan, Super U, Aldi + boucheries), liste de courses optimisée par magasin.

- Ouvrir : https://drsteack.github.io/chasse-aux-promos/
- Sur le téléphone : menu du navigateur → « Ajouter à l'écran d'accueil ».
- `promos.json` est mis à jour automatiquement le mardi et le jeudi.
